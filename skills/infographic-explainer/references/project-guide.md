# v0.2 project guide

## Everyday files and commands

- `assets/board.svg`: editable diagram content. The outer SVG width/height and viewBox should match `story.board` dimensions. Supply your own fonts via @font-face if needed.
- `story.json`: source of truth for canvas, board, named regions, camera targets, annotations, captions and audio.
- `build-report.json`: generated duration, resolved camera poses, measured audio lengths and suggested review times. Do not edit.
- `index.html.in` and `runtime.js`: engine sources; ordinary topic/aspect changes need not modify them.
- `index.html`, `story.js`, `assets/gsap.min.js`: generated by `pnpm build`; do not edit.

After `pnpm install`:

```sh
pnpm preflight
pnpm check
pnpm render --output renders/final.mp4 --quality high --workers 2
pnpm preview
```

Preview starts HyperFrames Studio in background mode. Verify the reported URL before sharing it. `pnpm test` exercises the named-region fitting and timing invariants. All time fields use seconds.

## Canvas presets

Set `canvas.preset` to `classic` (1440×1080), `landscape` (1920×1080), or `portrait` (1080×1920). Each defines camera viewport, margins, subtitle rail and font size. FPS defaults to 30. Optional width/height overrides must be even integers. Regions remain in board coordinates, so changing the preset recomputes framing without moving region boxes.

## Board source

```json
{"type":"svg","src":"assets/board.svg","width":1600,"height":1050,"label":"我的主题"}
```

`svg` inlines your authored SVG to retain vector text/layout inspection. Keep it a static diagram without scripts or external resources. For an existing image use `type: "image"`; the initializer's `--image` option copies a local PNG/JPEG/WebP/AVIF and reads its dimensions. It clears demo speech, captions and timing so unrelated narration is not attached to the new image. Add these yourself before delivering a narrated video.

An image fits its declared board rectangle with its aspect ratio preserved. Normally use intrinsic image dimensions as board dimensions. OCR or visual inspection can suggest boxes, but the engine does not itself recognize text or infer meaning. Bitmap detail must hold up at the planned zoom.

## Regions and camera targets

```json
"regions": {
  "overview": {"x": 0, "y": 0, "width": 1600, "height": 1050},
  "core-idea": {"x": 80, "y": 60, "width": 650, "height": 300},
  "keyword": {"x": 120, "y": 150, "width": 260, "height": 44}
},
"initialCamera": {"target": "overview"},
"shots": [{"start": 3, "duration": 1.2, "target": "core-idea"}]
```

The builder fits the target rectangle inside the camera viewport minus margins, with default `maxScale: 2.4`. A shot may override `padding` and `maxScale`; these affect breathing room and maximum magnification. Explicit `x/y/scale` is still available for deliberate manual framing. Named regions give reliable geometric framing, not automatic art direction.

For reference: `screenX = cameraX + scale * boardX`, likewise Y. Camera targets should include context; underline targets should tightly enclose one phrase. Avoid reusing a large card rectangle as a word underline.

## Temporary annotations

```json
{"id":"mark1","target":"keyword","start":5.2,"draw":0.7,"end":6.8}
```

No hand-authored SVG path is required. The builder draws just below the phrase rectangle, with optional `offset` (default 8 board pixels). `end` means fully invisible, not finished drawing. Leave at least 0.15s after drawing for the fade and usually some reading time. Distinct appearances need distinct IDs. Overlapping marks and marks during camera moves are rejected. `allowDuringMove: true` is an explicit opt-in for a deliberately simultaneous move and annotation, not the default style.

The cursor follows a measured SVG path. Use selector strings for SVG GSAP targets: direct element references lost marks in a v0.8.30 export despite a correct preview.

## Audio, voice and duration

```json
"audio": [{"start":0.5,"src":"assets/narration.wav","text":"这里是旁白"}],
"duration": "auto",
"tail": 0.3
```

`pnpm build` uses ffprobe to confirm an audio stream and measure its duration. Omit `audio.duration`. A stale manual duration is rejected instead of silently trimming or misaligning audio. `duration: "auto"` includes all camera moves, marks, captions and audio plus tail, rounded up to a whole frame. A numeric duration is allowed but must include every segment.

The bundled audio is macOS Tingting at rate 255. To regenerate test speech on a Mac from each audio entry's `text`:

```sh
pnpm narrate --voice Tingting --rate 255 --overwrite
pnpm build
```

Without `--overwrite`, existing destination audio is preserved and the command fails with an explanation. All clips are synthesized into staging before replacing them. This helper is macOS-only; existing audio and rendering are not. On other platforms use a recorder or available TTS provider and place files at the declared paths. The helper does not automatically move emphasis times after speech changes—review them by listening or using aligned timestamps.

A caption entry is `{ "start": 0.5, "end": 3, "text": "讲解字幕" }`. It can wrap in the subtitle rail; keep it short enough for at most two readable lines. Long speeches need multiple caption windows.

## Font and environment limits

Fonts are not bundled. Local board candidates are Kaiti SC / KaiTi / Noto Serif CJK SC, and subtitle candidates are PingFang SC / Microsoft YaHei / Noto Sans CJK SC. Check the actual output; a declared font name does not prove it is installed. Use the same licensed fonts for matching cross-machine output. The preflight checks Node/FFmpeg/ffprobe; HyperFrames checks its browser at render time. Do not claim Windows/Linux testing based only on the platform-neutral code.

## Updating an older project

The skill identifier stays `infographic-explainer`. Existing v0.1 projects can keep rendering with their original engine. v0.2 starts new projects with `version: 2`. To migrate a project, first create a new directory, move its diagram into `assets/board.svg` (or import the image), define regions, then copy/adapt audio and timing. Do not replace an existing project's engine blindly: the old inline SVG paths and manual camera config require migration.

## Optional transcript planner

For timed narration and region text/keywords, use `pnpm plan transcript.json` to create a separate draft and explanation report. See [transcript planning](transcript-planning.md). This is additive to the v0.2 format; existing projects and manual timelines remain valid.
